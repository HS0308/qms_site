What this tool is

A single self-contained HTML file for two QMS workflows — Close the Loop (CTL) coaching and audit score disputes — that any teammate can open directly in a browser with no install, no login, and no shared database. All records are stored in a plain Excel workbook (.xlsx) that you save and share yourself.

Sharing across the team without a cloud backend

  • Copy this coaching-disputes-tool.html file to any shared drive, USB, chat, or intranet link — each person opens it locally.
  • Click Save to Excel to download a .xlsx workbook with a Coaching (CTL) sheet and a Disputes sheet — this is the actual record.
  • Put that workbook on your normal shared drive / email / Teams / SharePoint. Whoever needs to add or update records clicks Open Excel file, picks that same workbook, and their entries load into the tool.
  • After adding new sessions/disputes, click Save to Excel again and re-upload the file to the shared location — this is the "sync" step, done manually so there is no live database or server anywhere.
  • The workbook can also be opened directly in Excel/Google Sheets/Numbers for reporting, filtering, or pivot tables — it's a plain spreadsheet, not a proprietary format.

Data location

While you're working in a session, unsaved entries are kept only in this browser tab's memory — closing the tab without clicking Save to Excel loses them. The .xlsx file you download is the single source of truth; there is no separate hidden storage, database, or cloud account involved.
