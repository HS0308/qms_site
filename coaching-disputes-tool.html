What this tool is

A single self-contained HTML file for two QMS workflows — Close the Loop (CTL) coaching and audit score disputes — that any teammate can open directly in a browser with no install, no login, and no shared database. Everyone's records live only in their own browser (localStorage).

Sharing across the team without a cloud backend

  • Copy this coaching-disputes-tool.html file to any shared drive, USB, chat, or intranet link — each person opens it locally.
  • Use Export team file (.json) to save a snapshot of your entries, then send that file to a supervisor/QA lead.
  • They use Import team file to merge those records into their own copy of the tool.
  • No server, no signup, no recurring cost, and no company data stored on any third-party cloud.

Data location

All data is stored under the browser's local storage key qms_local_v1. Clearing browser data, using a different browser, or opening the file in private/incognito mode will not show previously saved records unless you re-import an exported file.
