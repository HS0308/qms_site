What this tool is

A single self-contained HTML file for two QMS workflows — Close the Loop (CTL) coaching and audit score disputes — plus a lightweight sign-in so agent/supervisor names are logged automatically. All records are stored in a plain Excel workbook (.xlsx) — no server, login system, or cloud account behind it.

Automatic saving

  • In Chrome or Edge, click 🔗 Auto-save to file once, pick or create an .xlsx file — after that, every submission, resolution, or new user writes straight to that file on your disk automatically, no repeated downloads.
  • In other browsers (Firefox, Safari) that API isn't available, so use Save to Excel after you're done making changes, and Open to resume an existing workbook.

Sharing across the team without a cloud backend

  • Copy this coaching-disputes-tool.html file to any shared drive, USB, chat, or intranet link — each person opens it locally.
  • The workbook has three sheets: Coaching (CTL), Disputes, and Users — put it on your normal shared drive / email / Teams / SharePoint.
  • Whoever needs to add or update records clicks Open, picks that same workbook, signs in from the roster, and their entries save back into it.
  • The workbook can also be opened directly in Excel/Google Sheets/Numbers for reporting, filtering, or pivot tables.

Sign-in & data location

Sign-in is name-based (no password) purely to auto-fill and log who did what — it is not an authentication system. Nothing is written to browser storage; the current user is held only in this tab's memory and is cleared on Logout or when the tab closes. The .xlsx file is the single source of truth.
